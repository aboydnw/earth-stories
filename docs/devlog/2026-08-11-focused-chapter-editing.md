# Focused chapter editing and map composition

Earth Stories now treats chapter editing as a focused authoring task instead of
exposing the project schema as one long form.

The editor has three stable regions—Chapters, Canvas, and Edit—with accessible
tabs below 960px. The selected chapter renders through the same viewer-owned
renderer used by the full story. Map movement updates the project draft after a
short pause, with View changed/updated feedback, Undo, Fit, and Reset to the
last saved view. The full story remains an explicit preview mode and is forced
into view while publication snapshots are captured.

Chapter inspectors now follow the task order authors use: content, data, reader
behavior, layers, environment, then exact technical values. Image, video,
chart, and flyover chapters each have a purpose-built flow. Shared source
identity, delivery, appearance, filtering, legend, and provenance moved to
Story data with an explicit “affects every chapter” notice.

The chapter rail derives compact status from publisher readiness rather than
persisting duplicate workflow state. Flyovers gained captured-view cards,
captions, reorder and recapture actions, presets, scrub preview, and archival
caption fallback. Legacy projects remain valid because keyframe captions
default to empty strings.
