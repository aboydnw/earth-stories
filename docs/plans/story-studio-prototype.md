# Edge of Ice: Story Studio prototype

In an editable Edge of Ice copy, select **Two moments, the same fjord**, then **Open Story Studio**. Pick an element and choose **Sketch alternatives** to compare the static baseline, house, shoreline, or one compatible remix. The same playhead drives all treatments. **Read without motion** shows both observations and the missing months.

The canvas is a schematic illustration, not the published map. It uses the two unchanged endpoint geometries already bundled with the Kronebreen example, projected for a small SVG and revealed at separate beats. Only the illustration and framing move. Six known months with no front stay unrepresented. Pyles et al., v4, CC BY 4.0.

The rehearsal is an isolated authoring experiment. It needs no credentials, model or remote assets and does not edit the story, change the shared reader, or alter export. The toolbar and inspector follow the editor UI system; the color exceptions belong solely to the illustrative SVG and its evidence legend. These fixture-only treatments are not a new general-purpose writer or animation format.
